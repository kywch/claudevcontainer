# Behavior

This file is normative. A conflict with another normative artifact is a
specification defect that must be repaired.

## B1 Count Tokens

B1.1 The count operation accepts one input string.

B1.2 A token is any non-empty span between ASCII whitespace delimiters.

B1.3 Empty input and delimiter-only input return count `0`.
